# Changes

Everything below is relative to the uploaded `benchmark-frontend`. `benchmark-api` was not modified.

## Existing files modified

| File | Change |
| --- | --- |
| `Cargo.toml` | Added `gloo-net` (default features off, `http` only) and `serde_json`. Nothing else changed. |
| `tailwind.css` | Kept `@import "tailwindcss";` and added the design tokens in `:root` plus a small `@layer base`. The Dioxus CLI still compiles it automatically. |
| `src/main.rs` | Replaced the template (Hero, Blog, Navbar) with module declarations and `dioxus::launch(app::App)`. |
| `.env.development`, `.env.production`, `.env.example` | Added `API_BASE_URL`. `APP_PORT` is unchanged. |

## Existing files left as they were

`Dioxus.toml`, `xtask/`, `.cargo/config.toml` (`cargo dev` unchanged), `clippy.toml`, `AGENTS.md`, `assets/tailwind.css` (generated, regenerated by `dx serve`) and `assets/favicon.ico`.

`assets/main.css` and `assets/header.svg` are no longer referenced by the app. They can be deleted.
`src/config/` and `src/schemas/` were already unused by `main.rs` and still are.

## New structure

```text
src/
├── main.rs, app.rs, format.rs
├── shell/            sidebar, top bar, layout, not found
├── components/       shared UI only
└── features/
    ├── connection/   HTTP client, error type, connection indicator
    ├── charts/       SVG scales, line/area and bar charts
    ├── overview/     GET /benchmarks/overview
    ├── history/      GET /benchmarks
    ├── run_detail/   GET /benchmarks/{run_id}
    ├── comparisons/  GET /comparisons/summary?runIds=a,b
    └── submission/   POST /benchmarks
docs/backend-cors.md
```

## Routes

`/` overview, `/runs` history, `/runs/:run_id` detail, `/compare?baseline=&comparison=`, `/new` submission.
